## Font Family

Ayna UI uses **Source Code Pro** as its primary typeface - a monospace font that reinforces the brutalist aesthetic with its clean, technical character.

<div
	style={{
		padding: '24px',
		border: '2px solid #000',
		backgroundColor: '#f9f9f9',
		marginBottom: '24px',
	}}
>
	<code
		style={{ fontFamily: 'Source Code Pro, monospace', fontSize: '16px' }}
	>
		font-family: 'Source Code Pro', monospace;
	</code>
</div>

### Why Source Code Pro?

-   **Monospaced** - Every character has equal width
-   **Highly legible** - Optimized for readability
-   **Technical aesthetic** - Perfect for brutalist design
-   **Open source** - Free and widely available
-   **Fallback** - Uses system monospace if unavailable

## Line Height

We use **100% line height** for most UI elements to maintain the compact, tight aesthetic that defines brutalist design.

<div
	style={{
		padding: '24px',
		border: '2px solid #000',
		backgroundColor: '#f9f9f9',
		marginBottom: '24px',
	}}
>
	<code
		style={{ fontFamily: 'Source Code Pro, monospace', fontSize: '16px' }}
	>
		line-height: 100%;
	</code>
</div>

For longer text blocks and descriptions, use **140-150% line height** for better readability.

## Usage Examples

### Buttons

<div style={{ marginBottom: '24px' }}>
	<button
		style={{
			display: 'inline-flex',
			alignItems: 'center',
			gap: '10px',
			padding: '12px 20px',
			border: '2px solid #1e40af',
			background: '#3b82f6',
			color: '#fff',
			fontFamily: 'Source Code Pro, monospace',
			fontSize: '14px',
			fontWeight: 600,
			lineHeight: '100%',
			boxShadow: '-4px 4px 0px 0px #1e40af',
			cursor: 'pointer',
			transition: 'all 0.15s cubic-bezier(0.4, 0, 0.2, 1)',
		}}
		onMouseEnter={(e) => {
			e.currentTarget.style.transform = 'translate(2px, -2px)'
			e.currentTarget.style.boxShadow = '-6px 6px 0px 0px #1e40af'
		}}
		onMouseLeave={(e) => {
			e.currentTarget.style.transform = 'translate(0, 0)'
			e.currentTarget.style.boxShadow = '-4px 4px 0px 0px #1e40af'
		}}
		onMouseDown={(e) => {
			e.currentTarget.style.transform = 'translate(-2px, 2px)'
			e.currentTarget.style.boxShadow = '-2px 2px 0px 0px #1e40af'
		}}
		onMouseUp={(e) => {
			e.currentTarget.style.transform = 'translate(2px, -2px)'
			e.currentTarget.style.boxShadow = '-6px 6px 0px 0px #1e40af'
		}}
	>
		Click Me
	</button>
</div>

```css
font-family: 'Source Code Pro', monospace;
font-size: 14px;
font-weight: 600;
line-height: 100%;
```
