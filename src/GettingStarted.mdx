# Getting Started with Ayna UI

Welcome to **Ayna UI** - a brutalist/neobrutalist React component library built with TypeScript and styled-components.

## 🚀 Installation

Install the package via npm:

```bash
npm install ayna-ui styled-components
```

Or using yarn:

```bash
yarn add ayna-ui styled-components
```

**Note:** `styled-components` is a peer dependency and must be installed separately.

## 📦 Basic Usage

Import components from the package:

```jsx
import { Button, Input, Modal, Select } from 'ayna-ui'

function App() {
	return (
		<div>
			<Button variant="primary">Click me</Button>
			<Input placeholder="Enter text..." />
		</div>
	)
}
```

## 🎨 Design Philosophy

Ayna UI embraces **brutalist/neobrutalist design** principles:

-   **Bold borders**: 2px solid black borders on all interactive elements
-   **Sharp shadows**: `-4px 4px` box shadows for depth
-   **Monospace typography**: Source Code Pro font family
-   **High contrast**: Black and white with semantic color accents
-   **No subtle gradients**: Flat, honest, and direct visual language

## 🧩 Available Components

### Form Components

-   **Button** - Primary, secondary, success, danger, and warning variants
-   **Input** - Text inputs with label, error, and full-width support
-   **Select** - Custom dropdown with viewport-aware positioning
-   **Checkbox** - Styled checkboxes with labels

### Feedback Components

-   **Alert** - Dismissible alerts with 4 semantic variants
-   **Toast** - Auto-dismissing notifications with 6 positions
-   **Spinner** - Loading indicator with size variants
-   **Tooltip** - Hover-activated contextual help

### Layout Components

-   **Card** - Content containers with optional headers and footers
-   **Modal** - Dialogs with 3 size options and backdrop control
-   **Page** - Full page layout wrapper

### Data Display

-   **Badge** - Status indicators with semantic colors
-   **Avatar** - User avatars with initials or images
-   **Dropdown** - Action menus with icons and dividers

## 💡 Quick Examples

### Button with Variants

```jsx
import { Button } from 'ayna-ui';

<Button variant="primary">Primary</Button>
<Button variant="secondary">Secondary</Button>
<Button variant="success">Success</Button>
<Button variant="danger">Danger</Button>
```

### Form with Input and Select

```jsx
import { Input, Select, Button } from 'ayna-ui'

function Form() {
	const [name, setName] = useState('')
	const [country, setCountry] = useState('')

	const options = [
		{ value: 'us', label: 'United States' },
		{ value: 'uk', label: 'United Kingdom' },
		{ value: 'ca', label: 'Canada' },
	]

	return (
		<form>
			<Input
				label="Name"
				value={name}
				onChange={(e) => setName(e.target.value)}
				placeholder="Enter your name"
			/>

			<Select
				label="Country"
				options={options}
				value={country}
				onChange={setCountry}
				placeholder="Select country"
			/>

			<Button variant="primary" type="submit">
				Submit
			</Button>
		</form>
	)
}
```

### Modal Dialog

```jsx
import { Modal, Button } from 'ayna-ui'
import { useState } from 'react'

function ModalExample() {
	const [isOpen, setIsOpen] = useState(false)

	return (
		<>
			<Button onClick={() => setIsOpen(true)}>Open Modal</Button>

			<Modal
				isOpen={isOpen}
				onClose={() => setIsOpen(false)}
				title="Confirm Action"
				footer={
					<>
						<Button
							variant="secondary"
							onClick={() => setIsOpen(false)}
						>
							Cancel
						</Button>
						<Button
							variant="primary"
							onClick={() => setIsOpen(false)}
						>
							Confirm
						</Button>
					</>
				}
			>
				<p>Are you sure you want to proceed?</p>
			</Modal>
		</>
	)
}
```

### Toast Notifications

```jsx
import { Toast, ToastContainer } from 'ayna-ui'
import { useState } from 'react'

function ToastExample() {
	const [showToast, setShowToast] = useState(false)

	return (
		<>
			<Button onClick={() => setShowToast(true)}>Show Toast</Button>

			<ToastContainer position="top-right">
				<Toast
					message="Operation successful!"
					variant="success"
					isVisible={showToast}
					onClose={() => setShowToast(false)}
					duration={5000}
				/>
			</ToastContainer>
		</>
	)
}
```

## 🎯 TypeScript Support

All components are built with TypeScript and include full type definitions:

```tsx
import { ButtonProps, InputProps, ModalProps } from 'ayna-ui'

// Component props are fully typed
const MyButton: React.FC<ButtonProps> = (props) => {
	return <Button {...props} />
}
```

## 🔧 Component Props

Each component comes with comprehensive props for customization:

-   **Common props**: `className`, `style`, `disabled`, etc.
-   **Variant props**: `variant`, `size`, `color` for visual variations
-   **Callback props**: `onClick`, `onChange`, `onClose` for interactions
-   **State props**: `isOpen`, `isVisible`, `isSelected` for controlled components

Explore individual component documentation for detailed prop information.
